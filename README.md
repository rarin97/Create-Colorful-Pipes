# Create: Colorful Pipes
## Features

Adds 16 colored variants of

- Fluid Pipes
- Glass Fluid Pipes
- Smart Fluid Pipes
- Encased Fluid Pipes
- Fluid Valves
- Fluid Pumps 
- Fluid Tanks
- Boiler Gauges
- Item Drains
- Spouts
- Hose Pulleys
